# 📄 Smart Resume Builder

A simple web application that helps users create a professional resume by filling out a form.  
The project is built using **HTML, CSS, JavaScript, and Flask**, where Flask receives the user's information and displays it inside a resume template.

---

## ✨ Features

- Clean and modern Home Page.
- User-friendly Resume Form.
- Generate a professional resume instantly.
- Print the generated resume.
- Form validation using HTML.
- Simple JavaScript interactions (alerts, reset confirmation, print).

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript

- Flask

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/ResumeGen.git
```

2. Open the project folder

```bash
cd ResumeGen
```

3. Install Flask

```bash
pip install flask
```

4. Run the application

```bash
python app.py
```

5. Open your browser

```
http://127.0.0.1:5000
```
